DISPLAY NAME
SoundSwitch Tray

STORE DESCRIPTION
SoundSwitch Tray is a small Windows notification-area utility for switching between connected playback devices. Click its loop icon to cycle from speakers to headphones or another enabled audio output. Windows playback defaults for multimedia and communications change together.

The tray icon uses the active device's assigned color, with preferences remembered locally across restarts and reconnects. Hover over the icon to see the active output and connected device count. The app refreshes automatically when outputs are connected, disconnected, or changed in Windows. With zero or one output, switching is disabled.

SoundSwitch Tray runs 100% offline, collects zero personal data, and makes zero network requests. There are no accounts, advertisements, analytics, or telemetry. Its only saved data is local audio device color preferences in %LOCALAPPDATA%\SoundSwitch\colors.xml.

Launch SoundSwitch Tray once from Start after installation. Windows startup is enabled by default so the tray utility stays available after logon; users can disable it in Settings > Apps > Startup. Windows may initially place its icon in the notification-area overflow menu. Right-click the icon and select Exit SoundSwitch to close it. The app runs as the current user without administrator elevation. A named mutex prevents duplicate tray instances. Applications that use their own fixed audio output may keep that selection.

Requires Windows 10 version 2004 (build 19041) or later, or Windows 11. At least two connected, enabled playback devices are needed to cycle outputs.

RESTRICTED CAPABILITY JUSTIFICATION: runFullTrust
SoundSwitch Tray is a classic .NET Framework WinForms tray utility, packaged as an AnyCPU desktop executable. It requires runFullTrust to run with Windows.FullTrustApplication, create its notification-area icon, and enumerate and cycle Windows default playback devices through Windows Core Audio COM interfaces. It uses IMMDeviceEnumerator to enumerate enabled playback endpoints and IPolicyConfig.SetDefaultEndpoint to update Windows playback defaults after an explicit user click. These existing desktop operations require the full-trust WinForms process rather than a UWP app container. The embedded executable manifest specifies asInvoker with uiAccess=false: no administrator elevation is requested. The app has zero networking or telemetry and stores only local audio device color preferences in %LOCALAPPDATA%\SoundSwitch\colors.xml. No other capabilities are declared.
